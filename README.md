## QC Benchmark for Nanopore Reads

This repository contains the code and benchmarking pipeline for our paper: **Evaluating Nanopore read trimming and quality filtering in bacterial genomics**.

The study systematically assesses the performance of Oxford Nanopore Technologies (ONT) adapter trimming and quality-processing tools, evaluating their impact on key downstream bacterial genomics applications such as *de novo* genome assembly and variant calling.
